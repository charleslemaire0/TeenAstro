# TeenAstroUploader for Windows

> Groups.io hub: https://groups.io/g/TeenAstro/wiki/8837  
> Related pages: Telescope · Focuser · Hand controller · [Auto! and EEPROM](TeenAstroUploader_Auto_EEPROM.md) (wiki 10404)

Save mount / focuser parameters before upgrading firmware.

On TeenAstro **1.5+**, the Windows Uploader can do that itself with **Auto!** and **EEPROM**.

## Install

1. Download **TeenAstroUploader.msi** from the current release (`Released data/Firmware/` on GitHub).
2. Run the installer. Start **TeenAstro Firmware Uploader** from the Start Menu.

Windows 10 and Windows 11.

## Download firmware

1. Select **Firmware Version**.
2. Choose **Stable** or **Latest**.
3. Press **Download!** — **Open Folder** shows the files.

## Requirements

- Hand controller and MainUnit from the **same release**
- **Auto!** / **EEPROM** need firmware **1.5+**
- Parameter JSON backups: `%LocalAppData%\TeenAstro\Config\`
