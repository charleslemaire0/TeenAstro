Hello everyone,

For some time, many of us have used Jürgen Goldan’s TeenAstroConfig to back up mount parameters, edit them, and write them back — especially before a firmware update or a factory reset. That tool has been very useful to the community.

With TeenAstro 1.5 and newer, the Windows TeenAstro Firmware Uploader now covers the same ground inside the same application that already flashes the MainUnit, Focuser, and Hand Controller. The idea is simply to reduce the number of separate utilities needed for a typical upgrade, while keeping the workflows that people already know.

TeenAstroConfig.exe remains available if you prefer it or already have setups stored in its files. Nothing forces a change of habit; the Uploader is an integrated option for current firmware.

What the Uploader adds for parameters (1.5+)

  • Auto! — on the Telescope or Focuser tab: detect the board, save parameters to a JSON file, flash the selected firmware, restore after reboot, then re-read and verify. Useful when you want a single-button upgrade path.
  • EEPROM — a full parameter editor with the same grouping as the Webserver (Mount, Motors, Speed, Limits, Encoders, Site, Tracking). Read / Write / Save / Load. After a write, values are read back and checked.
  • Two mounts — TeenAstro stores two mount profiles; the editor can switch the active mount (reboot) and edit the selected one.
  • Firmware older than 1.5 is left alone for backup/restore: use Upload! only, and keep saving settings the way you already do (including TeenAstroConfig if that is your workflow).
